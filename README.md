# 📌 ConformidadeDeclarativa

Projeto composto por **backend** e **frontend** para análise de conformidade declarativa.

Como rodar o backend:

* Instalar docker
* docker-compose up --build (criar o container)
* docker-compose up (subir o container)

Por configuração, o docker roda na porta 5000 do localhost



Como rodar o frontend:

* Entrar na pasta ConformidadeDeclarativaWeb/frontend
* rodar npm install
* rodar ng serve para subir o frontend

Por configuração o frontend roda na porta 4200



Link para acessar a ferramenta: [https://conformidade-declarativa.vercel.app/](https://mp-conformance-checking.vercel.app/)
